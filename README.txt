CANDRIVA — interactive beta UI reference. Not a production signal or payments service. For user privacy, no founder identity or personal wallet is shown. Candriva is a brand identity only; regulated operator disclosures may still be required. The 24-hour trial, subscriber management, payments, real trading alerts, and full account authentication are not operational. Timed reminders and price alerts work while the browser page is open, with optional browser notification permission. Public quotes and price candles are proxied from an existing public market feed; no private portfolio data is used.
